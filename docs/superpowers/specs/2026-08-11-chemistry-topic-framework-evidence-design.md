# 化学专题官方框架佐证设计

## 背景与决定

`v1.11` 已完成数学目录边界、英语单元目录证据和物理专题官方框架佐证。化学现有 10 个原创专题、40 个知识点、12 个方法模板、28 条方程式和 8 个实验已通过结构、准确性与高风险字段检查，但尚无与物理同等粒度的专题框架佐证记录。

本批采用“独立官方框架佐证记录”方案。它为现有专题建立可追溯快照和公开来源观察，使专题标题、稳定 ID、当前内容容器和来源登记能够一起复核。用户已授权按推荐顺序推进，本文件将该范围视为本批规格确认。

不采用两种替代方案：

1. 不做任何记录：不会误导，但化学专题的来源边界无法由构建期自动回归。
2. 直接建立教材逐章映射或外部内容导入：目前没有逐章官方目录和逐条原始资料，越过了可验证证据的范围。

## 可用证据与边界

本批只使用已登记的官方来源：

1. 教育部《义务教育化学课程标准（2022年版）》作为课程框架基线。
2. 教育部《2024年义务教育国家课程教学用书目录》作为人教版化学九年级上下册版本/册次目录观察。
3. 人教社《人教版义务教育化学新教材培训会在成都举办》作为教材修订与编写思路培训的公开语境。

这三项资料只能支持“项目原创专题与公开课程、教材版本语境在宏观领域上相容”。它们不证明专题等同于教材章节，也不提供教材正文、原题、原图或逐章顺序。

证据记录必须显式排除：`教材逐章标题`、`教材章节顺序`、`教材册次映射`、`教材正文与原始插图`。它不是 `external-source` 输入，不改变内容源跟进报告的 `blocked` 状态，也不解除 `math-chapters-v1.11` 的官方逐册目录门禁。

## 数据设计

新增 `docs/evidence/chemistry-topic-framework-review-2026.json`，只保存元数据，不保存知识正文、例句、方程式、实验步骤或图片路径：

```json
{
  "schemaVersion": 1,
  "reviewId": "chemistry-topic-framework-support-2026-v1",
  "reviewedAt": "2026-08-11",
  "evidenceKind": "official-framework-support",
  "scope": { "supports": [], "notVerified": [] },
  "sources": [{ "key": "...", "title": "...", "url": "...", "role": "...", "observation": "..." }],
  "topics": [{ "id": "...", "title": "...", "reviewSnapshotHash": "...", "frameworkDomains": ["..."] }]
}
```

记录必须覆盖现有 10 个稳定专题，顺序与 `packages/chemistry/data/chemistry-topics.js` 一致：实验安全、空气氧气、水与溶液、微粒与元素、化学用语与守恒、碳与燃料、金属、酸碱、盐化肥、材料资源环境。`frameworkDomains` 是项目内部的简短领域标签，不得被表述为官方章节名称。

## 构建期校验

新增 `scripts/check-chemistry-topic-framework-evidence.js` 与对应 Node `assert` 契约测试。检查器只在构建期加载化学数据，公开接口为：

```js
checkChemistryTopicFrameworkEvidence({ evidencePath } = {})
// => { topicCount: 10, sourceKeys: [...], evidenceKind: 'official-framework-support' }
```

检查器必须：

1. 将缺失或无效 JSON 包装为明确的“化学专题官方框架佐证记录读取失败”错误。
2. 严格校验根字段、来源字段、专题字段和禁止字段；禁止教材映射、`sourceKind`、外部输入路径、正文和资源路径等越界字段。
3. 交叉验证 3 个来源键、标题、URL、官方域名、角色和简短观察文本，拒绝来源注册表漂移。
4. 对 10 个当前专题生成稳定快照哈希，校验标题、专题 ID、领域标签、复核快照和公共 `contentMeta` 的已复核状态。
5. 不写入运行时数据，不调用内容源输入/外部 manifest 工具，不修改分包、稳定 ID、云资源、本地存储或页面路由。

快照投影只包含专题容器的稳定结构：`id`、`themeId`、`title`、`summary`、`objective`、`gradeBands`、`keywords`、`knowledgeIds`、`templateIds`、图示 ID/标题/说明和封面路径。这样实际专题内容变化会触发复核，但不会把知识正文复制进证据文件。

## 质量门禁与文档

默认 `scripts/check-v1.11-quality-matrix.js` 新增该契约测试，固定检查数量由 117 更新为 118；矩阵自身的契约测试同时锁定该命令与新数量。

`docs/v1.11五科学科高风险字段复核记录.md` 与 `docs/v1.11后续开发路线.md` 记录本批的支持范围和未验证范围，保留外部资料接入、数学逐册目录和实体设备发布门禁。

## 验收标准

- 10 个化学专题均有唯一、可复算的快照和非空内部领域标签。
- 记录只使用 3 个已登记官方来源，来源 URL、角色和观察文本任一漂移都会失败。
- 在 JSON 中加入教材章序、正文、外部输入或资源路径字段会失败。
- 缺失/损坏记录会失败；默认记录通过并输出 `OK chemistry topic framework evidence: 10 topics`。
- 质量矩阵为 118 项且全部通过；化学准确性、高风险批次、内容审计与发布准备检查保持通过。
- 不出现任何小程序页面、正文、稳定 ID、云资源、本地数据或功能变化。
