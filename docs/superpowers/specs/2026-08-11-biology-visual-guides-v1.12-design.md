# 生物关键图解 v1.12 设计规格

**日期：** 2026-08-11
**分支：** `codex/biology-visual-guides-v1.12`
**基线：** `9e6189c`（v1.11 生物专题框架证据已校验）

## 目标

为现有 6 个生物专题、36 个知识点补充原创的结构化“关键图解”。图解把抽象关系转成可直接阅读的流程、对比、循环或层级，不依赖位图中的小字号文字；即使云端专题封面加载失败，学生也能完整理解关键关系。

本批只增强知识查阅体验，不新增测评、学习任务、打卡、错题、账号或云同步功能。

## 范围与非目标

### 纳入

- 36 个既有 `bio-k-*` 知识点各有 1 个 `visualGuide`。
- 支持四种语义类型：`flow`、`cycle`、`compare`、`hierarchy`。
- 生物知识点页在“概念说明”之后显示结构化关键图解；现有专题封面继续作为补充图像保留。
- 为数据字段、覆盖率、节点数量、类型和值建立构建期校验。
- 在内容审计中记录每个图解的可追溯内容来源，但不改变既有知识点的复核等级。

### 不纳入

- 不绘制或上传 36 张新的位图图解；避免云资源和小屏文字可读性的额外风险。
- 不改变知识点、专题、模板、云资源和收藏的稳定 ID。
- 不把官方教材的正文、插图、练习题或解析写入图解。
- 不把当前宏观官方来源升级为能逐条证明细节的 `verified` 证据。

## 数据模型

`packages/biology/data/biology-knowledge.js` 中每个 `defineKnowledge()` 输入新增 `visualGuide`：

```js
{
  type: 'flow', // flow | cycle | compare | hierarchy
  title: '根吸收水和无机盐的路径',
  summary: '从土壤到植物各部分的物质移动关系。',
  items: [
    { label: '土壤水和无机盐', note: '根毛周围的可利用物质', tone: 'blue' },
    { label: '根毛细胞', note: '扩大接触面积并完成吸收', tone: 'green' },
    { label: '导管运输', note: '把水和无机盐送往地上部分', tone: 'amber' }
  ]
}
```

字段规则：

| 字段 | 规则 |
|---|---|
| `type` | 仅允许 `flow`、`cycle`、`compare`、`hierarchy`。 |
| `title` | 非空、面向当前知识点，最多 24 个字符；不复述大段正文。 |
| `summary` | 非空，最多 72 个字符，简要交代读图目的。 |
| `items` | 2 至 5 个，`label` 非空、最多 32 个字符且同一图解内唯一；`note` 非空、最多 96 个字符。 |
| `tone` | 仅允许 `green`、`blue`、`amber`、`slate`；只做视觉分组，不表达绝对对错。 |
| `lane` | 仅 `compare` 可使用 `left` 或 `right`；两侧都必须至少有一个节点，其他类型不得包含该字段。 |
| `depth` | `hierarchy` 的每个节点必须使用整数 0、1 或 2；其他类型不得包含该字段，不用它表达知识难度。 |

类型语义：

- `flow`：按观察、条件或物质变化的顺序阅读，节点之间显示方向箭头。
- `cycle`：展示持续关联的环节，并用文字说明其循环或持续关系；默认不把最后一个节点画成对第一个节点的因果箭头，也不把末项直接导致首项写成因果关系。只有内容本身已明确支持闭环时，才可以在说明中表达回到起点的关系。
- `compare`：两个核心对象交替呈现，节点按左右列归属显示，说明相同主题下的差别。
- `hierarchy`：由整体到局部或由分类大类到小类的层级关系，节点使用逐级缩进和连接线。

`visualGuide` 内容必须是基于本知识点现有 `summary`、`knowledgePoints` 和原创例子重新组织的原创短语；不得储存图片 URL、外部链接、教材页码或长段引用。

## 页面与交互

位置固定为：知识点标题与核心知识 → 概念说明 → **关键图解** → 现有专题封面 → 核心解释与其他内容。

- 图解默认展开，不增加额外操作门槛。
- 每个节点显示序号、名称和简短说明；文字随阅读显示设置换行，不裁切、不横向滚动。
- `flow` 使用纯 WXML/CSS 的方向连接符；`cycle` 使用持续关系提示而非默认闭环箭头；`compare` 由数据预处理明确拆成左右两个列容器，不依赖 CSS Grid 对稀疏节点的自动放置；`hierarchy` 使用固定级距。
- 图解是独立的文字内容，图片加载失败不影响它；专题封面仍沿用已有“图示暂未加载，完整文字知识仍可继续阅读”降级文案。
- 缺少图解的历史或异常内容不导致页面空白，页面仅跳过该区块，并由构建期检查阻止正式内容遗漏。

## 验证策略

新增 `scripts/check-biology-visual-guides.js` 及测试，检查：

1. 36 个生物知识点均存在且仅存在一个有效图解。
2. 所有类型、色调、标题、说明与节点数量符合模型规则。
3. 节点标签在同一图解中唯一，且不含图片 URL、HTML 或长文本复制痕迹。
4. 至少覆盖四种图解类型，避免整科退化成一种机械版式。
5. 页面 WXML 对有图解和无图解两种状态均具备可渲染分支。
6. 既有 `check-biology-content.js`、`check-content-audit.js --require-reviewed`、`check-v1.11-quality-matrix.js` 与发布配置校验继续通过。

## 验收标准

- 36/36 个生物知识点显示关键图解，且与当前知识点的核心关系一致。
- 文字在小屏下可换行，结构不依赖位图加载。
- 不改变任何稳定内容 ID、云图片路径、路由路径或本地存储版本。
- 无新版权来源或未复核教材文本进入项目。
- 已完成本次实际运行的 Node 图解契约、页面语义、生物内容、严格内容审计和 121 项全量质量矩阵检查。iPhone/Nexus 5 模拟器页面回归以及实际设备发布回归仍待独立执行，后者继续沿用 v1.10.1 证据流程。
