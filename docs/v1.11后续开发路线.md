# 知识通 v1.11 后续开发路线

> 路线状态：规格已确认，实施从 `codex/roadmap-v1.11` 开始
>
> 当前运行版本：`1.10.1-dev.1`
>
> 发布分支：`codex/release-regression-v1.10.1`

## 1. 目标与边界

v1.11 的目标是把五科学科内容维护变成可重复、可核对、可回归的开发流程，重点解决教材来源映射、内容复核和发布前差异控制。v1.11 不以新增页面或增加学习任务为目标。

产品继续保持纯知识查阅：不加入在线测评、自动评分、学完自测、单元输出任务、错题本、打卡、家长端、强制登录、云同步或未经人工审核的 AI 讲解。

本路线不改变现有稳定 ID、云资源路径、本地存储版本或备案信息。教材照片、自有教辅和公开资料只用于核对课程边界与知识关系，正文、例句、示例、解析和插图继续原创整理。

## 2. 当前规格确认

### 2.1 产品规模

| 学科 | 当前范围 | v1.11 处理方式 |
|---|---|---|
| 数学 | 29 章、29 专题、89 个教材小节、36 个方法模板 | 优先建立新版教材逐册/小节证据映射，不凭历史章序重排 |
| 英语 | 5 册可学习内容、42 个单元、336 个详细词条、84 个语法点；官方结构为 6 册/44 个正式单元 | 维护既有五册；九年级下册已确认 5 个正式单元和 2 个选学戏剧，标题资料核对前保持空缺 |
| 物理 | 22 章、84 个知识点、29 个实验、28 个方法模板 | 继续复核公式、单位、方向、实验和图示，不破坏章节 ID |
| 化学 | 九年级 10 个专题 | 维护专题、知识点、实验、方程式和图片失败降级 |
| 生物 | 6 个单元、36 个知识点、6 个方法模板 | 维护单元、知识点、观察说明和窄屏显示 |

### 2.2 运行与发布规格

- 主包、数学、英语、物理、化学和生物继续按普通分包运行，公共组件和轻量搜索索引留在主包。
- 内容仓库继续使用静态 JavaScript，构建期生成搜索索引、审计报告和资源清单。
- 本地记录继续使用 `subjectId:type:id`，不因路线文档升级存储版本。
- 云图片失败时必须保留完整文字内容；未准备好云环境时不得调用无效云接口。
- 运行时版本在 v1.10.1 发布闭环前保持 `1.10.1-dev.1`；不在路线分支提前伪造 `1.11.0` RC。

## 4. 阶段 1：v1.11 来源地图与内容维护

### 4.1 数学新版目录映射

数学新版教材的处理顺序固定为：官方目录证据收集 -> 结构差异报告 -> 稳定 ID 映射 -> 页面显示核对 -> 回归检查。

已公开确认的结构变化可以记录为映射；未取得逐册官方目录时，必须保留 `needs-official-volume-map` 边界。不得因为目录顺序变化而：

- 直接用章节序号重建主键；
- 批量重命名 `ch*`、专题、知识点或模板稳定 ID；
- 删除现有章节或将历史内容强行归入猜测的新版章节；
- 用搜索结果、培训机构目录或单张教材照片替代官方逐册证据。

每个完成的映射至少记录：稳定 ID、教材版本、册次、显示标题、官方小节、来源 URL/PDF、核对日期、变更原因和是否影响旧别名。

### 4.2 英语教材映射

英语五册现有单元和详细词法/语法内容继续保持可查阅。人教社公开介绍已确认九年级下册有 5 个正式学习单元和 2 个选学戏剧；只有在正式目录、单元标题和可靠教材文件完成交叉核对后才扩充。此前只记录结构待核对项，不创建空单元、不编造单元标题、不把能力专题伪装成教材单元。

已有词条和语法点的维护必须保留英式主拼写、美式变体、IPA、词性、可数性/及物性、搭配、原创例句、辨析和复核来源字段。

### 4.3 物理、化学和生物维护

按小批次复核以下高风险字段：

- 物理：符号、单位、方向、公式条件、实验步骤、误差、安全提醒和图示连线；
- 化学：化学式、反应条件、配平、实验现象、结论和图片文字降级；
- 生物：术语、观察对象、实验步骤、结论、单元父级和窄屏文字布局。

每次只处理一个明确批次，完成后立即生成差异报告和检查结果。内容准确性问题与页面交互问题分开提交，避免难以定位回归来源。

## 5. 阶段 2：内容生产与审计底座

在阶段 1 的来源地图稳定后，再逐步建设：

1. 结构化内容输入格式，支持稳定 ID、父级、别名、来源和复核状态；
2. 构建期 schema 校验、搜索索引生成、图片资源检查和差异报告；
3. 人工复核队列，区分待核对、已核对和已发布状态；
4. 小批次内容预览，确保正文、图示和搜索结果同时可回归。

运行时仍加载构建产物，不把数据库、后台编辑器、登录或云同步引入 v1.11 的第一批任务。

## 6. 分支与提交规则

### 发布分支

`codex/release-regression-v1.10.1` 只接受以下变更：发布配置、包体/设备证据工具、云运行时阻塞修复、与发布直接相关的文档。未通过严格门禁前，不创建 RC。

### 路线分支

`codex/roadmap-v1.11` 用于路线文档、来源地图工具和后续内容维护。路线分支不代替发布分支的实体设备证据，也不把未发布内容上传为正式体验版。

### 热修复分支

如果 v1.10.1 实体回归发现问题，从最终冻结提交建立独立 `codex/release-hotfix-*` 分支。热修复只包含复现所需的最小改动，不合并 v1.11 内容。

### 单批提交顺序

```text
规格/来源记录 -> 数据或工具实现 -> 页面适配 -> 校验与差异报告 -> 文档 -> 回归结果
```

每个提交保持一个可解释主题；不要把大批量内容改写、图片替换和路由重构放进同一提交。

## 8. 暂不做的事情

- 不在 AppID、包体和实体设备证据缺失时创建 RC；
- 不把模拟器截图写成实体设备通过；
- 不猜测新版数学逐册章序或英语九下单元；
- 不复制教材正文、课文、题目、解析、听力材料或原书插图；
- 不引入测评、任务、错题、打卡、家长端、登录、云同步或自动生成内容；
- 不升级本地存储版本，不改稳定 ID，不删除历史别名；
- 不因一次内容批次顺便重构公共路由、分包边界或云函数。

## 9. 下一批具体任务

实施顺序已确认如下：

1. 完成发布分支的 AppID/开发者工具绑定，生成真实包体报告；
2. 由用户在 iPhone 和 Android 实体设备完成 A1-A15 并保存证据文件；
3. 发布分支通过严格门禁后创建 `1.10.1-rc.1`，上传体验版并单独处理审核反馈；
4. 在本路线分支新增数学新版逐册目录证据表和差异报告字段；
5. 核对英语九年级下册官方资料，确认后再决定是否建立单元数据；
6. 按数学、英语、物理、化学、生物的高风险字段顺序做小批复核；
7. 每批通过结构、准确性、搜索、资源和回归检查后再推送。

当前最先可执行且不依赖外部账号状态的工作，是第 4 项：完善来源地图和差异报告工具；发布体验版相关工作仍等待 AppID 绑定、包体报告和实体设备证据。

数学新版目录证据表当前由 `packages/math/data/math-curriculum-baseline.js` 保存，差异报告由 `scripts/build-math-curriculum-audit.js` 生成；`scripts/math-volume-map.test.js` 会拒绝把未核对的官方册次、章号或标题写入报告。

物理、化学和生物本批高风险字段复核结果见《v1.11五科学科高风险字段复核记录》。
