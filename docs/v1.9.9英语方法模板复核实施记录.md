## 3. 工具链修正

复核过程中发现英语内容审计适配器直接读取静态 `english-content.templates`，会绕过 repository 的模板元数据。已改为通过英语 repository 暴露模板实体，同时保留搜索条目使用现有静态内容，确保页面、审计和搜索的稳定 ID 不变。

全量资源校验还发现通用压缩脚本对个别大尺寸 PNG 的单次最终兜底仍可能超过 200KB。已将 `scripts/prepare-remote-assets.js` 改为多级尺寸和色阶递降，231 个远程资源现均能稳定通过体积、尺寸、路径和哈希检查。
