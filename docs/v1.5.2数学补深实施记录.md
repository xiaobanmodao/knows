# v1.5.2 数学补深实施记录

当前版本：`1.5.2-dev.1`

开发分支：`codex/math-depth-v1.5.2`

更新日期：2026-08-01

## 1. 本版范围

本版只补深数学知识内容和查阅呈现，不增加测评、任务、错题、打卡、登录或云同步。29 个稳定章节、89 个教材小节、36 个方法模板和旧链接 ID 均保持不变。

内容继续依据教育部《义务教育数学课程标准（2022年版）》、义务教育国家课程教学用书目录和人教版公开教材介绍核对边界。教材用于确认知识范围，讲解、推导、例题和跨学科说明均为原创整理。

## 2. 数据补深

- 新增 `packages/math/data/details/math-lesson-depth.js`，为 89 个稳定小节 ID 逐项配置详情。
- 每个小节固定包含两层成立条件：章节通用边界和本小节必要条件。
- 每个小节包含独立推导链，明确从已有定义或公式如何到达结论。
- 每个小节包含独立的“为什么成立”，不使用跨章节通用占位文案。
- 建立 12 类人工复核的跨学科联系，覆盖基准与方向、公式变形、测量误差、坐标图像、比例、受力、光路、函数、统计、空间模型、效率最值和概率。
- 每条详情带 `detailVersion: 2`、稳定 `lessonId`、搜索词和已复核元数据。

运行时通过 repository 合并详情，旧数学数据模块和稳定 ID 不改动。本地收藏、最近浏览、阅读位置、笔记和标签继续按原 ID 打开，因此存储版本保持 4。

## 3. 页面呈现

通用 `content-block` 新增 `reasoning` 类型，在数学知识页依次展示：

1. 成立条件。
2. 从已知到结论的推导步骤。
3. 推导得到的公式或结论。
4. 为什么成立。
5. 与物理、测量、统计或工程情境的联系。

推导块支持复制，长文本使用正常换行，不依赖图片传递核心关系。数学原有学习说明、具体知识点、公式、知识关系表、方法顺序和例题均保留。

## 4. 搜索与校验

- 构建期搜索索引继续保持 833 个实体，没有增加重复页面入口。
- 数学知识索引纳入成立条件、推导关系、原因、跨学科关键词和“为什么成立”入口。
- 搜索“勾股定理为什么成立”“数轴方向翻转”“现实可行域”“随机误差”可直达相应数学小节。
- 新增 `scripts/check-math-depth.js`，固定检查 89 个详情、89 条唯一推导、89 条唯一原因和 12 类跨学科联系。
- 通用 schema 增加 `mathDetail` 与 `reasoning` 内容块校验。
- 继续运行数学准确性检查，固定守住 SSA、分式定义域、增根、判别式、等可能概率、反比例函数分支、坡度和三视图等边界。

当前相对 v1.3 基线的内容差异为新增 0、修改 710、删除 0。其中数学新增修改 29 章和 89 个教材小节共 118 项；英语、物理沿用此前已经通过的 592 项修改，没有内容 ID 删除或失效。

## 5. 后续

完成开发者工具 iPhone 与 Android 模拟器、包体和控制台回归后提交本分支。下一阶段进入 `v1.6.0` 查阅效率建设：公式、单词、语法和实验索引，搜索高亮，笔记筛选，本地导出恢复和阅读设置；仍保持纯知识查阅定位。
