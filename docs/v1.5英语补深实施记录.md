# v1.5 英语补深实施记录

当前版本：`1.5.0-dev.1`

开发分支：`codex/english-depth-v1.5`

分支基线：提交 `7010e06`，v1.4 分包与云资源签名链路保持不变。

## 一、已完成范围

- 七年级上册 3 个预备单元和 7 个正式单元，共 80 个词、20 个语法点。
- 七年级下册 8 个正式单元，共 64 个词、16 个语法点。
- 八年级上册 8 个正式单元，共 64 个词、16 个语法点。

- 272 个词全部补充 UK/US IPA、词法属性、结构化词形、搭配释义、第二例句和易混辨析。
- 68 个语法点全部补充使用条件、3 种结构变式、易混对比、结构化语法图和第 3 组例句。
- 英语实体数量保持 42 单元、336 词、84 语法，例句总数由 504 增至 844。

## 二、兼容结构

- 补深字段位于独立详情模块，通过稳定单词和语法 ID 合并到原单元数据。
- 九上维持原始对象形状，页面按基础字段降级，不生成空详情。
- 收藏、最近浏览、搜索锚点和页面路由未改变，本地存储结构仍为版本 4。
- 内容差异报告预期为新增 0、修改 374、删除 0，对应 34 单元、272 词和 68 语法。

## 三、单元页

- 增加全部、表达、单词、语法四种筛选。
- 单词默认展示词头、音标、词性和释义，展开后显示详细词法、搭配、例句、辨析和提醒。
- 语法补深内容使用 WXML/CSS 绘制时间线、句子成分和对比图，不新增云图片依赖。
- 搜索直达单词或语法时自动切换对应分区；单词目标同时自动展开并滚动定位。

## 四、搜索与校验

- 主包索引继续保持 833 项，只增加词形、英美拼写、短搭配和语法结构关键词，不收录长例句。
- `spelt`、`spelled`、`color`、`geese`、`practice`、`temperatures`、`一般过去时`、`名词性物主代词`、`There be`、`a piece of advice`、`the elderly`、`be used to doing`、`recommend doing` 均进入回归基线。
- 新增 `check-english-depth.js`，并继续运行英语准确性、内容 schema、搜索索引、内容差异和分包边界检查。
