## 1. 实施范围

本阶段为数学、英语和物理知识页增加统一的 `Aa 阅读` 设置，并在“我的”页提供同一入口。可选项固定为：

- 字号：小、标准、大。
- 行距：紧凑、标准、舒展。
- 图片宽度：窄 `72%`、适中 `86%`、全宽 `100%`。

默认为标准字号、标准行距和全宽图片。阅读令牌只作用于正文、讲解、实验内容、题目内容、笔记正文和教学图片；标题、标签、按钮、固定字段标签和导航保持原尺寸。知识页通过 `onShow` 重新读取偏好，以接收从“我的”页返回后的变更。

## 3. 偏好与备份契约

阅读偏好使用独立本地键，完整结构为：

```js
{
  version: 1,
  fontSize: 'standard',
  lineHeight: 'standard',
  imageWidth: 'full'
}
```

- 缺失、未知或非法字段按字段回退到默认值，公共方法始终返回完整的归一化对象。
- 保存失败时页面保留本次会话偏好并提示“设置未保存”，不改写阅读位置、收藏、笔记或折叠状态。
- 内容存储版本保持 `4`，备份文件格式保持 `knows-local-backup` v1。
- 新备份包含归一化后的 `readingPreferences`。恢复新备份时应用其偏好；旧备份缺少该字段时保留当前偏好。
- 阅读偏好参与恢复的原子写入和回滚，任一后续写入失败时恢复到导入前快照。
