# v1.11 数学新版目录证据表实施记录

## 1. 本批范围

- 分支：`codex/roadmap-v1.11`
- 目标：建立数学新版教材逐册目录证据表和机器校验字段。
- 本批不改变运行时章节顺序、稳定章节 ID、lessonId、旧链接、收藏、笔记或本地存储版本。

## 2. 已完成内容

1. 在 `packages/math/data/math-curriculum-baseline.js` 增加 `volumeMap` 契约。
2. 逐项列出 29 个稳定章节的证据记录，记录来源 ID、状态、核对日期和未核对说明。
3. 在 `scripts/math-curriculum-audit.js` 中生成 `volumeMap` 报告字段，包含当前运行时显示快照和官方映射占位状态。
4. 在目录审计中加入防误填规则：未取得逐册官方目录时，`official` 必须为 `null`。
5. 新增 `scripts/math-volume-map.test.js`，并接入 `check-release-readiness.js`。
6. 差异报告新增 `sourceMap`，明确 10 项完成映射所需证据字段，并统计当前已映射/待映射章节。
7. 差异报告新增 `stability`，同时核对 29 个章节、89 个稳定 `lessonId` 和 89 条 `chapterId-lesson-N` 旧别名，识别缺失、漂移、孤立目标和稳定 ID 冲突。
8. 差异报告新增 `diffSummary`，固定输出新增、修改、删除数量及每条结构变化的当前映射状态。

## 3. 当前状态

当前 29 条记录均为 `needs-official-volume-map`。这表示稳定容器已经列出，但新版教材逐册原始章序尚未由完整官方目录逐条证明。教育部课程标准、国家课程教材目录和人教社新版介绍继续作为来源边界，不把第三方目录或照片当作逐册证据。

当前机器报告的稳定性结果为：章节 `29/29`，知识小节 `89/89`，旧别名 `89/89`，缺失、漂移、孤立目标和重复稳定 ID 均为 `0`。这证明现有迁移兼容层稳定，但不代表新版教材逐册章序已经完成核对。

当前差异汇总为：新增 `0`、修改 `2`、删除 `0`。两条修改分别是函数内容拆分（已映射到稳定容器）和数据分析新增内容（仍待逐册小节映射）。

### 3.1 本轮官方资料检索结论（2026-08-10）

- 人教社新版数学介绍继续确认“函数”与“一次函数”拆分，以及“数据的四分位数”“数据的分组”新增内容，但没有公开 29 章逐册原始目录表，不能直接填入 `volumeMap.official`。
- 人教社 2026 年“义务教育中学数学教材”页面目前公开的是教材介绍页和图片/下载占位，不提供可逐条核对的册次、章号和小节文本，因此只作为资料发现记录，不加入正式映射来源：<https://www.pep.com.cn/rjyx/qnbjsjc/sytj/202604/t20260420_2006456.shtml>。
- 人教社旧版数学产品页仍可检索到 2011 年版或实验版目录，不能替代 2022 年版新版目录；本轮不将其作为新版证据。
- 结论：`volumeMap` 继续保持待核对状态，暂不重排章节、改写稳定 ID 或创建猜测的册次目录。

### 3.3 外部目录接入校验器（2026-08-10）

- 新增 `scripts/math-volume-map-input.js` 和 `scripts/check-math-volume-map-input.js`，固定未来官方逐册目录的外部输入协议。
- 输入必须包含 29 个稳定章节，且按 `STABLE_CHAPTER_IDS` 顺序排列；根级来源必须完整覆盖数学目录基线的三类官方来源，每条记录必须提供官方年级、册次、章号、标题、小节、官方来源键、复核日期、变化原因和旧别名影响说明。
- 校验器拒绝当前源版本、占位文本、未知或重复稳定 ID、非官方来源、缺失小节和未声明稳定 ID/lessonId/旧别名保持关系的输入；只生成 `dist/content-audit/math-volume-map-input.json`，不修改运行时目录。
- 接入命令：`node scripts/check-math-volume-map-input.js <official-volume-map.json> --report dist/content-audit/math-volume-map-input.json`。拿到真实官方目录后，先通过此校验器，再人工核对 `volumeMap` 和稳定迁移差异。

### 3.2 来源键统一核对（2026-08-10）

- 数学目录基线原先使用的 `moe-math-standard-2022` 已迁移为统一注册表中的 `moe-math-curriculum-2022`；教育部教材目录和人教社新版介绍继续使用各自已登记的规范键。
- 数学目录审计现在同时校验来源键是否登记、来源类型是否为 `official`、标题和 URL 是否与 `data/content-source-registry.js` 一致，避免目录审计单独维护一套官方域名和来源命名。
- 本次只更新构建期来源标识和差异报告哈希，不改变章节 ID、`lessonId`、旧别名、收藏目标或 `needs-official-volume-map` 状态。

当某一册的完整官方目录可以核对时，下一批只允许：

- 填写对应记录的官方年级、册次、章号、标题和小节；
- 添加直接来源 URL/PDF、核对日期和证据说明；
- 生成差异报告，确认稳定 ID、旧别名和收藏目标不变；
- 通过数学内容、路由、迁移和发布准备检查后再调整显示映射。

## 4. 验证命令

```bash
node scripts/math-volume-map.test.js
node scripts/build-math-curriculum-audit.js
node scripts/check-math-curriculum-audit.js
node scripts/check-release-readiness.js
```

本批只新增审计字段和测试，不新增知识正文、题目、图片或用户功能。

报告字段检查还应关注：

- `sourceMap.pendingEvidenceFields` 不得被误解为已完成的官方映射；
- `stability.status` 必须为 `verified`，且旧别名差异数组保持为空；
- `diffSummary.counts` 只能反映已记录的结构变化，不能代替官方逐册目录。
