# v1.11 数学新版目录证据表实施记录

## 1. 本批范围

- 分支：`codex/roadmap-v1.11`
- 目标：建立数学新版教材逐册目录证据表和机器校验字段。
- 本批不改变运行时章节顺序、稳定章节 ID、lessonId、旧链接、收藏、笔记或本地存储版本。

## 2. 已完成内容

1. 在 `packages/math/data/math-curriculum-baseline.js` 增加 `volumeMap` 契约。
2. 逐项列出 29 个稳定章节的证据记录，记录来源 ID、状态、核对日期和未核对说明。
3. 在 `scripts/math-curriculum-audit.js` 中生成 `volumeMap` 报告字段，包含当前运行时显示快照和官方映射占位状态。
4. 在目录审计中加入防误填规则：未取得逐册官方目录时，`official` 必须为 `null`。
5. 新增 `scripts/math-volume-map.test.js`，并接入 `check-release-readiness.js`。

## 3. 当前状态

当前 29 条记录均为 `needs-official-volume-map`。这表示稳定容器已经列出，但新版教材逐册原始章序尚未由完整官方目录逐条证明。教育部课程标准、国家课程教材目录和人教社新版介绍继续作为来源边界，不把第三方目录或照片当作逐册证据。

当某一册的完整官方目录可以核对时，下一批只允许：

- 填写对应记录的官方年级、册次、章号、标题和小节；
- 添加直接来源 URL/PDF、核对日期和证据说明；
- 生成差异报告，确认稳定 ID、旧别名和收藏目标不变；
- 通过数学内容、路由、迁移和发布准备检查后再调整显示映射。

## 4. 验证命令

```bash
node scripts/math-volume-map.test.js
node scripts/build-math-curriculum-audit.js
node scripts/check-math-curriculum-audit.js
node scripts/check-release-readiness.js
```

本批只新增审计字段和测试，不新增知识正文、题目、图片或用户功能。
