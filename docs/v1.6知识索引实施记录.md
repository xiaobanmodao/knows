# v1.6 知识索引实施记录

当前版本：`1.6.0-dev.1`

开发分支：`codex/reference-indexes-v1.6`

更新日期：2026-08-01

## 1. 本阶段范围

本阶段建设公式、单词、语法和实验索引，不增加新的知识层级，也不加入测评、任务、错题、登录或云同步。索引条目只保存稳定内容 ID、容器 ID 和页面内定位 ID，正文仍由对应学科分包按需加载。

## 2. 索引规模

| 索引 | 条目 | 数据来源 |
|---|---:|---|
| 公式 | 173 | 数学 89 个教材小节、物理 84 个教材知识点 |
| 单词 | 336 | 英语五册详细词条，复用主包搜索索引 |
| 语法 | 84 | 英语五册详细语法点，复用主包搜索索引 |
| 实验 | 29 | 物理教材知识点中的结构化实验 |

总计 622 个查阅入口。单词和语法不生成重复数据，运行时直接从现有 833 条轻量搜索索引筛选；新生成文件只包含 173 条公式和 29 条实验摘要。

## 3. 页面与直达

- 新增主包页面 `/pages/reference-index/index`，使用公式、单词、语法、实验四段选择。
- 公式支持数学、物理筛选；其余类型直接固定到实际学科，不显示无意义筛选项。
- 当前类型内支持标题、公式、单位、搭配、语法结构、器材、现象和结论搜索。
- 首屏最多传入 60 条，触底后分批显示，避免一次性渲染 336 张单词条目。
- 单词和语法沿用英语单元页现有的展开与滚动定位。
- 实验入口携带稳定 `experimentId`，物理知识页加载后定位到对应实验块。
- “我的”页新增四类索引入口和实际条目数量。

## 4. 构建与校验

- `scripts/build-reference-index.js` 从数学和物理完整数据生成 `data/reference-index.js`。
- `scripts/check-reference-index.js` 比较生成源码和内容源哈希，校验 622 个唯一索引键、学科规模、必要字段、实验定位路由和代表性关键词。
- `check-content-routes.js` 增加物理实验页面内定位参数回归。
- `check-package-boundaries.js` 继续保证主包不直接引用三科全文数据。

代表性检索固定覆盖：`勾股定理为什么成立`、`kg/m³`、`spelled`、`colour`、`There be`、`名词性物主代词`、`晶体熔化`和`伏安法`。

## 5. 搜索体验第二阶段

- 新增双向别名表，同组词形、英美拼写、概念名称和公式名称可从任一写法查找。
- 统一处理全半角、上下标、乘除号、减号和空格差异，`v＝s／t`、`a²+b²=c²` 等写法可以稳定命中。
- 搜索页和知识索引页对标题、摘要、公式与标签做安全文本分段高亮，不拼接 HTML。
- 关联别名命中时显示实际匹配词，避免用户只看到结果却不知道命中依据。
- `scripts/check-search-semantics.js` 校验别名唯一性、双向展开、公式规范化、高亮范围和代表性公式检索。

## 6. 本地笔记第一阶段

- “我的”页集中显示笔记总数和筛选后的实际数量。
- 支持数学、英语、物理学科分段筛选，以及标签使用次数聚合。
- 支持标题、正文、上下文和标签关键词搜索，并复用安全文本高亮。
- 学科、标签和关键词可组合使用，重置后恢复全部笔记。
- 旧笔记缺少学科时继续按数学解析，不升级存储版本，也不改写原始记录。
- `scripts/check-note-filters.js` 校验排序、旧记录兼容、标签聚合和组合筛选。

## 7. 本地数据备份与恢复

- 备份覆盖收藏、最近浏览、搜索记录、阅读位置、继续阅读、本地笔记和数学年级偏好。
- 文件格式固定为 `knows-local-backup` v1 JSON，包含应用版本、内容版本、生成时间、数量和数据校验和。
- 导出写入固定本地文件后调用微信文件转发，不累计临时备份文件；不支持转发时，须再次确认后才复制备份文本。
- 恢复只接受 `2MB` 以内的知识通备份，先检查格式、版本、时间和校验和，再显示文件来源与各类数据数量。
- 合并恢复按稳定 `subjectId:type:id` 去重并保留更新时间较新的记录；覆盖恢复必须二次确认。
- 写入任一存储项失败时回滚到恢复前快照，并刷新应用会话中的收藏、最近浏览和搜索历史。
- 旧数学收藏、笔记、最近浏览、阅读位置和继续阅读统一经过稳定 ID 迁移。
- 备份文件可能包含用户自己记录的笔记正文，应用不上传文件，并在导出区明确提示妥善保管。
- 发布前若隐私接口检测列出 `chooseMessageFile`，用途应填写为“用于用户主动选择知识通备份文件并在本机恢复收藏、笔记和阅读记录”，不得描述为上传到服务器。
- `scripts/check-local-backup.js` 校验损坏 JSON、文件上限、未来版本、校验和、合并、覆盖和写入失败回滚。

## 8. 后续顺序
