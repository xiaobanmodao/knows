# 知识通 v1.10 规格确认记录

> 确认基线：`e0a6e09`
>
> 当前开发版本：`1.10.1-dev.1`
>
> 当前分支：`codex/release-regression-v1.10.1`

## 1. 产品范围

- 服务名称：知识通。
- 服务内容：初中数学、英语、物理、化学和生物知识库。
- 使用方式：游客直接查阅，支持全局搜索、收藏、最近浏览、知识笔记、标签和阅读显示设置。
- 数据边界：收藏、笔记、阅读记录和显示设置只保存在本机，不要求注册，不上传学习记录。
- 当前版本不包含：测评、学完自测、单元输出任务、在线答题、自动评分、错题本、打卡、家长端、教师端、登录、云同步和 AI 问答。

## 2. 技术规格

- 主包只保留首页、搜索、收藏、我的、公共组件、轻量学科清单和搜索索引。
- 数学、英语、物理、化学和生物分别使用普通分包，按用户首次进入时加载。
- 内容通过稳定的 `subjectId`、`type` 和内容 ID 路由，不把页面路径写入本地记录。
- 云图片加载失败时保留标题、正文、公式、实验步骤和图示说明；云环境未就绪时不发起无效云请求。
- 分包运行时不得加载 Node.js 内置模块；构建期的哈希和审计工具可以使用 Node.js。

## 3. 内容规格

- 数学保留 29 个稳定章节、29 个专题、89 个教材小节和独立方法模板。
- 英语按教材册次和单元组织，保留单词、搭配、语法和原创例句的查阅结构。
- 物理按人教版八上、八下和九年级全一册组织，保留知识点、公式、实验、图示和方法模板。
- 化学和生物保持独立主题、知识点、实验或观察说明和方法入口。
- 新增内容使用原创改写，不复制教材正文、题目、解析、听力材料或原书插图。

## 4. 数学新版目录边界

人教社公开介绍明确说明新版数学教材将原一次函数内容拆分为“函数”和“一次函数”两章，并在“数据的分析”中增加“数据的四分位数”和“数据的分组”两节内容（[人教版义务教育数学新教材介绍](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202408/t20240826_1994351.html)）。

当前运行内容已经覆盖四分位数和数据分组知识，但正式逐册章序映射仍保持 `needs-official-volume-map`。教育部公开的《2024年义务教育国家课程教学用书目录》用于确认教材版本和册次范围，不足以证明新版数学的完整逐册原始目录（[2024年义务教育国家课程教学用书目录](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020240805496325238752.pdf)）。

因此本版本：

- 不重排 `ch01` 至 `ch29` 的稳定章节 ID。
- 不把当前显示顺序宣称为新版官方章序。
- 不猜测新增小节所属册次或原始章号。
- 等逐册官方目录完成核对后，再单独提交显示映射和别名迁移。

## 6. 发布门槛

在创建 RC 或上传体验版前必须同时满足：

1. iPhone 实体设备完成 A1-A15，所有用例通过并有截图。
2. Android 实体设备完成 A1-A15，所有用例通过并有截图。
3. 使用当前最终构建生成 Developer Tools 包体报告，不能沿用历史报告。
4. 严格执行 `node scripts/check-release-readiness.js --require-device-evidence`。
5. 全量 `scripts/check-*.js` 通过，控制台项目错误为 0。

当前外部阻塞：项目配置中的 AppID 格式和本地读取均正常，但开发者工具上传日志仍返回微信服务端 `41002 appid missing`，因此尚未生成当前包体报告；实体设备证据也尚未录入。需要在开发者工具中确认当前登录账号与该 AppID 的开发权限和项目绑定。阻塞解除前保持 `1.10.1-dev.1`，不创建 RC。
