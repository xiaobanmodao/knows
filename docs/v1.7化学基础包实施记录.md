## 1. 版本目标

本版本把原有三科硬编码底座改造成声明式多学科架构，并交付首个可独立查阅的初中化学基础包。产品继续保持纯知识查阅定位，不加入测评、任务、错题、打卡、登录或云同步。

## 2. 内容依据与边界

本版以以下官方资料核对范围：

1. 教育部《义务教育课程方案和课程标准（2022年版）》：<https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html>
2. 教育部 2024 年义务教育国家课程教学用书目录：<https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020250418502592948423.pdf>
3. 人教版第十二套义务教育教材介绍：<https://www.pep.com.cn/xw/zt/hd/12/>
4. 人教版义务教育化学新教材培训说明：<https://www.pep.com.cn/rjdt/rjdt/202405/t20240517_1992181.shtml>

化学内容按课程标准五个学习主题组织，不把未经可靠核对的新版教材章号作为稳定 ID。教材只用于核对课程边界，讲解、示例和图示均为原创整理；危险操作明确限定在教师指导和合规学校实验室中进行。

## 4. 架构与交互

- `data/subject-manifest.js` 统一声明学科状态、分包、页面能力、参考类型和首页规模，首页、搜索和“我的”不再维护三科分支逻辑。
- `scripts/subject-adapters/` 统一向搜索索引、参考索引、内容清单和 schema 校验提供四科构建数据。
- `packages/chemistry/` 提供学科、专题、知识点和方法四类页面及本地 repository，不建立内容为空的教材章节页。
- 化学已接入搜索、参考索引、收藏、最近浏览、笔记、阅读位置、阅读显示设置和云图片文字降级。
- 方程式和实验支持稳定 `focusId` 直达；旧三科搜索与参考语义哈希保持不变。
- 本地记录继续使用 `subjectId:type:id`，存储版本保持 4，不迁移或上传用户数据。

## 5. 自动校验

本轮全量矩阵覆盖学科注册、构建适配器、化学结构与准确性、四科内容、页面、搜索、参考索引、迁移、笔记、备份、阅读设置、图片、分包边界、schema、内容差异、云图片运行时和发布配置。

已验证的关键结果：

- 除精确包体外的 34 项自动检查在当前工作树全部退出 0；包体检查必须等待同一提交生成的新预览报告，不使用旧报告代替。
- 5 个主题、10 个专题、40 个知识点、12 个方法、8 个实验和 28 条方程式引用完整且 ID 唯一。
- 28 条方程式通过元素守恒、条件和安全边界检查；8 个实验通过结构与安全字段检查。
- 35 张化学图片均为 `1280 x 900` PNG，内容哈希互不重复；最大压缩文件为 `204,673` 字节，低于 `200 KiB` 门槛。
- 四科远程资源清单共 753 项，路径、尺寸、压缩文件和内容哈希检查通过。
- 内容差异为新增 67、修改 710、删除 0；修改来自统一多学科元数据与索引重建，没有删除旧内容实体。
- 发布配置检查通过，主包未直接引用四科全文，分包之间没有内容模块交叉引用，也未配置自动预下载；发布信息会自动核对所有启用学科和版本号格式。
- 包体门槛从启用学科清单自动生成，当前要求主包小于 `700 KiB`、数学/英语/物理/化学各自小于 `1 MiB`，后续新增学科不会再依赖手写检查列表。

开发者工具精确预览包体报告和双模拟器回归已完成，验收数据见第 8 节；化学云目录实传证据仍不作为本轮分包验收的前置条件。在实体设备回归完成前不创建 RC 标签。

## 6. 资源与云端状态

本地源图位于 `assets/figures/generated/chemistry/`，发布压缩目录位于 `dist/remote-assets/assets/figures/generated/chemistry/`，目标云路径保持同名。文字内容不依赖云图片，资源请求失败时页面仍可完整阅读。
